Zwecke und Rechtsgrundlagen der Datenverarbeitung

Die Website dient der Darstellung unseres Unternehmens, unserer Einrichtungslösungen und der Bereitstellung von Kontaktmöglichkeiten. Bei der technischen Auslieferung der Website können Verbindungsdaten verarbeitet werden. Rechtsgrundlage ist grundsätzlich Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an einem funktionsfähigen und sicheren Internetauftritt).

Sofern Sie uns außerhalb dieser Website direkt kontaktieren, richtet sich eine etwaige Verarbeitung Ihrer Angaben nach dem jeweiligen Anliegen, insbesondere Art. 6 Abs. 1 lit. b oder lit. f DSGVO.

Kategorien personenbezogener Daten

Beim Aufruf einer Website können insbesondere IP-Adresse, Datum und Uhrzeit des Zugriffs, angeforderte Dateien, Browserinformationen, Betriebssystem sowie technische Fehler- und Statusinformationen verarbeitet werden.

Hosting über GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt, einen Dienst der GitHub, Inc. Bei der Auslieferung können technische Verbindungsdaten durch den Hostinganbieter verarbeitet werden. Einzelheiten zur Datenverarbeitung finden Sie in der Datenschutzerklärung von GitHub. Dabei kann eine Verarbeitung außerhalb der Europäischen Union stattfinden.

Kontaktformular

Auf unserer Kontaktseite können Sie Angaben in Formularfelder eingeben. Das Formular dient der Darstellung einer Kontaktmöglichkeit. Die Schaltfläche „Anfrage abschicken“ übermittelt derzeit keine Eingaben. Die eingegebenen Angaben werden durch diese Formularfunktion weder an uns versendet noch in einer Datenbank der Website gespeichert. Eine Bearbeitung der eingegebenen Anfrage findet daher nicht statt.

Empfänger personenbezogener Daten

Technische Daten können im Rahmen der Bereitstellung der Website vom Hostinganbieter verarbeitet werden. Eine Übermittlung der Formulareingaben an FORMA Raumkonzepte GmbH findet über die Website nicht statt.

Externe Bildquellen

Auf einzelnen Seiten werden Fotografien von externen Bildservern eingebunden, insbesondere von Unsplash. Beim Abruf solcher Bilder kann der jeweilige Anbieter technische Verbindungsdaten wie Ihre IP-Adresse erhalten. Die Verarbeitung erfolgt durch den jeweiligen Anbieter nach dessen Datenschutzbestimmungen. Weitere Informationen finden Sie unter unsplash.com/privacy.

Cookies und Analyse

Die Website setzt nach ihrer derzeitigen Gestaltung keine eigenen Analyse- oder Marketing-Cookies ein. Dienste wie Google Analytics, Google Maps, YouTube oder ein Cookie-Einwilligungsmanager sind nicht eingebunden. Unabhängig davon können Drittanbieter im Rahmen ihrer eigenen Dienste technische Daten verarbeiten.

Speicherdauer

Die Website speichert keine über das Kontaktformular eingegebenen Informationen. Für technische Verbindungsdaten beim Hosting gelten die Aufbewahrungs- und Löschregelungen des Hostinganbieters. Soweit im Einzelfall eine sonstige Kommunikation erfolgt, werden Daten nur so lange verarbeitet, wie dies für den jeweiligen Zweck oder aufgrund gesetzlicher Aufbewahrungspflichten erforderlich ist.
